### Injury table structure
One row per (ev_id, Aircraft_Key, inj_person_category in {Flig, Pass, Cabi, LapC}, injury_level in {FATL, SERS, MINR, NONE, TOTL}). Count column inj_person_count. Fatalities for an aircraft = SUM of FATL rows over categories. The TOTL row is unreliable: blank in 46% of cases, and where present it differs from FATL+SERS+MINR+NONE in 13,261 of 26,812 checks - do not use TOTL. Rows per aircraft: 5 (12,442 aircraft), 7 (7,761), 4 (3,281), 2 (2,497), 8 (961); 30,400 of 32,010 aircraft have injury rows (1,610 have none). Recent cases may have only e.g. Flig FATL=1, Flig NONE=0, Flig TOTL blank (no SERS/MINR rows). Event-level inj_tot_f equals sum of FATL rows for all events.

### mdb-export CSV dialect (default flags)
- Comma separated, header row first, UTF-8 (parsed cleanly as utf-8), text values double-quoted, numbers unquoted, NULL = empty unquoted field (`,,`), empty string vs NULL not distinguishable in practice.
- Embedded double quotes doubled (""). Embedded newlines inside quoted text: yes, in narratives (14,708 rows have LF in accf/cause; 13,528 rows contain CR, i.e. CRLF inside text); file line separator itself is LF only (495,607 CRLF pairs but they are inside narratives). Must use a real CSV parser, not line splitting.
- Dates: "MM/DD/YY HH:MM:SS" two-digit year (events.ev_date, lchg_date). Floats printed plainly (dec_latitude 49.216634 / 38.223888). Booleans/small ints as 0/1.
- Booleans in Findings cm_inPc not inspected.
